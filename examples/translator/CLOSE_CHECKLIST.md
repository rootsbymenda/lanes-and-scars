# Close checklist

Invented example; the template, with Nora in it. Run when Nora says "close it". In this order. Each step is a write, not a thought.

1. **The paragraph into the lane.** `lanes/{lane}.md`, section Sessions, newest first, dated. What was done. What Nora decided, in her words. What is next. Where the files are. New scars, by name.
2. **The lane's pickup.** Rewrite the Pickup section: the one next action and what it needs.
3. **The lane's line on the switchboard.** Rewrite it: date, state in one sentence, next. The old line goes to `chronicle/` verbatim, dated.
4. **The scars.** Every correction Nora made this session that should hold next time: one file in `rules/{area}/`, in the format, with the transcript line. One line each in `MEMORY.md`.
5. **The router.** If a lane, a folder or a path was born, `MEMORY.md` points to it.
6. **The thin check.** The switchboard fits on one screen. `MEMORY.md` is hooks only. If not, thin now, not next time.
7. **Say what you wrote.** Nora reads the paragraph before the window closes. The paragraph is the handoff; nothing else is.

If the window dies before this runs, the next window still has the transcript. That is what `tool/` is for.
