# The glossary is the client's word. Read it before any term we have seen before.

Invented example. Area: method · Earned: 2026-03-11 · Lane: client-glossaries

## The words

"we have a glossary for this. read it before you touch a term we have seen before. my memory is not the source and neither is yours. the file is." — Nora, 2026-03-11

## The incident

The law-firm March batch. The draft rendered "Mahnung" as "reminder" in four files. The client's glossary row says "dunning notice", with a note that the client's own templates use it. The term had been translated as "reminder" in a session in February, and the memory note from that session carried it forward. Nora caught it on the second file and stopped the batch.

## Why

A client's glossary is part of the contract: the same German term comes out as the same English term in every file, and the client chose the term. A memory of an earlier rendering is a copy of a copy; the glossary is the original. When the two disagree, the glossary is right by definition, and the memory is wrong by definition.

## How to apply

- Before translating a term that could have a fixed rendering, look it up in the client's glossary file. Not in memory, not in an earlier draft.
- If the glossary and a memory note disagree: use the glossary, delete or correct the memory note in the same session, and say so in the close paragraph.
- If the term is not in the glossary: mark it `[?]` with the candidates (ruling of 2026-04-02). Never choose silently.
- The lookup is cheap. Do it every time.
